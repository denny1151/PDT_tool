      怎麼看這張表
      參考價 400 C，為什麼表上顯示 300 C 買？
      400 C 是 poe.ninja 單件估價，用來算買入上限。300 C 來自 GGG 的歷史成交均價。兩者的交易對和時間可能不同。能否用 300 C 買到，要看弗斯特當前掛單。
      C 買・D 賣、D 買・C 賣怎麼算？
      各自用 GGG 的成交總額除以成交件數，再乘上試算件數。買入向上取整，賣出向下取整。C 買・D 賣是「收到的 D × 匯率 − 花掉的 C」，反向則是「收到的 C − 花掉的 D × 匯率」。只有 D/C 匯率會影響換算，該物品的單件參考價不影響這兩欄。
      歷史毛利代表什麼？
      兩條路線中較高的整批毛利，折成 C，未扣費用。例如 1,771 C 買、13 D 賣，按 1 D = 156.2 C，毛利為 259.6 C。
      毛利／1k 金幣怎麼算？
      各路線分別用歷史毛利 ÷ 估算金幣 × 1,000，取效率最高的一條。買入時按收到的物品數計費，賣出時按收到的 C 或 D 數計費。兩筆費用取整後相加，實際費用看弗斯特。
      為什麼有些價差留白？
      可能缺任一交易對、成交件數未達門檻，或整批賣不到 1 顆通貨。每批件數留空時，會用能同時換到至少 1 C、1 D 的最小批量試算。
      「歷史」是哪個小時？
      優先取上一個整點小時，缺資料時再往前一小時。以上方 GGG 時間為準，例如 09:00 代表 09:00–10:00。重讀快照只載入已發布的資料。
